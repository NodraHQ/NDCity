# Ideias para depois

- **Chat que renova sozinho**: assinatura mensal no cartão pelas Assinaturas do
  Mercado Pago (hoje cada compra dá 30 dias e não renova).
- **E-mail opcional na conta** para recuperar a senha sem depender do admin.
- **Limite de tentativas de login no banco** (hoje fica na memória de cada
  servidor da Vercel).
- **Chat em tempo real** com Supabase Realtime (hoje atualiza a cada 4 s).
- **Limpeza automática** de visitas com mais de 1 ano.
- **Backup**: botão no admin para exportar tudo (o plano grátis do Supabase não
  tem backup para baixar).
- Mais tipos de construção e enfeites; ranking de cidades.
